# Website Specification

## Website Purpose

Academic personal website for Tingjia Xu.

Overall visual direction:

- clean
- academic
- editorial
- minimal
- lively but not flashy
- avoid commercial portfolio styling

## Global Navigation

- Home
- Research
- Publications
- Projects
- Activities
- Hobbies

## Header

Header identity:

> Hi, I'm Tingjia.

Rules:

- entire text is black
- minimal and understated
- do not apply orange accent to any part of the header identity unless explicitly requested

The formal profile name on the Home page remains:

> Tingjia Xu

## Accent Colors

Structural / active accent: `#CA611A`

Body links / highlighted entities: `#D65828`

Rules:

- site remains primarily white, black, and muted grey
- orange is an accent only
- do not introduce default blue links
- ordinary bold text remains black

## General UI Rules

- avoid heavy cards
- avoid strong shadows
- avoid unnecessary borders
- use controlled whitespace
- avoid oversized headings
- do not automatically hyphenate words
- avoid awkward word breaks
- do not create placeholder pages
- do not create dead links
- do not add decorative images simply for visual uniformity
- approved pages are locked unless the user explicitly requests changes
